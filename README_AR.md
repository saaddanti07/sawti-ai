# صوتي AI — تحويل النص العربي إلى صوت

موقع ويب عربي بسيط لتحويل النص المكتوب إلى كلام بصيغة MP3.

## المزايا
- واجهة عربية متجاوبة للكمبيوتر والهاتف.
- أصوات عربية متعددة، منها أصوات جزائرية (أمينة وإسماعيل).
- أصوات نسائية ورجالية ولهجات عربية أخرى.
- التحكم في سرعة القراءة ودرجة الصوت.
- تشغيل النتيجة داخل الموقع وتنزيل ملف MP3.
- حد أقصى 5000 حرف لكل عملية في النسخة الأولية.

## ملاحظة مهمة حول المجانية والخصوصية
المشروع يستخدم مكتبة `edge-tts` للوصول إلى خدمة تحويل الكلام عبر الإنترنت في Microsoft Edge.
لا يحتاج المستخدم إلى مفتاح API مدفوع في الاستخدام المعتاد، لكن الخدمة تتطلب اتصالاً بالإنترنت وقد تتغير إمكانية الوصول إليها أو شروطها. النص الذي تحوله يُرسل إلى الخدمة الخارجية لمعالجته؛ لا تستخدمه للنصوص السرية أو الحساسة.
خطة الاستضافة المجانية قد تتضمن حدوداً أو توقفاً عند الخمول، حسب مزود الاستضافة.

## التشغيل محلياً
يتطلب Python حديثاً (يفضل 3.10 أو أحدث).

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

pip install -r requirements.txt
uvicorn app:app --reload
```

افتح: http://127.0.0.1:8000

## النشر كموقع عام مجاناً (Render)
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع جميع ملفات هذا المشروع إلى المستودع.
3. افتح Render وأنشئ Web Service واربطه بمستودع GitHub.
4. سيقرأ Render إعدادات `render.yaml` تلقائياً. إذا طلب إعداداً يدوياً:
   - Build command: `pip install -r requirements.txt`
   - Start command: `uvicorn app:app --host 0.0.0.0 --port $PORT`
5. انتظر انتهاء النشر وافتح رابط الموقع.

## ملاحظات التطوير
- هذه نسخة MVP أولية وليست خدمة إنتاجية كبيرة.
- قبل فتحها للجمهور، أضف حماية من إساءة الاستخدام وتحديد معدل الطلبات وتنظيفاً دورياً للملفات المؤقتة.
- قد تحتاج أسماء الأصوات إلى تحديث إذا غيّرت Microsoft قائمة الأصوات.
